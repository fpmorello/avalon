# AGENTS

Read and follow the [contribution guidelines](./CONTRIBUTING.md).

- Do not push, open pull requests, create issues or call the GitHub API unless the
  maintainer explicitly asks for it in the current session.
- Never copy builds, saves or keys to a console's SD card or NAND on your own.
- Keep comments to a reasonable level. Do not overexplain or add/remove comments from
  unrelated parts of the codebase.
